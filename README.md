# Greengreen — 3 ảnh sản phẩm — GitHub Pages

Bộ code dùng đúng **3 ảnh sản phẩm bạn đã gửi** làm gallery:

- `greengreen-1.jpg`
- `greengreen-2.jpg`
- `greengreen-3.jpg`

## Đăng lên GitHub Pages

Upload toàn bộ file vào repository:

```text
index.html
style.css
script.js
greengreen-1.jpg
greengreen-2.jpg
greengreen-3.jpg
```

Sau đó vào:

**Settings → Pages → Deploy from a branch → main → / (root) → Save**

Trang sẽ có dạng:

`https://TEN-GITHUB.github.io/TEN-REPOSITORY/`

Gallery có:
- Nút ảnh trước/sau
- 3 thumbnail để bấm chuyển ảnh
- Tự giữ đúng tỉ lệ ảnh
- Responsive trên điện thoại

Giỏ hàng và lựa chọn biến thể hiện là frontend demo, chưa kết nối database/thanh toán.
